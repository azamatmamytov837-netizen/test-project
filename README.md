# 🎬 Telegram-бот для сценариев Reels

Бот на базе Claude (Anthropic API), который пишет готовые к съёмке сценарии
для Instagram Reels / TikTok / YouTube Shorts под твой блог.

Каждый сценарий содержит:
- 3 варианта хука на первые 0–3 секунды;
- раскадровку по секундам: что в кадре, что говорить, какой текст на экране;
- призыв к действию, подпись к посту, хэштеги;
- советы по съёмке, монтажу и музыке.

После сценария можно просить правки: «короче», «добавь юмора», «перепиши под 15 секунд» —
бот помнит текущую тему.

## Команды бота

| Команда | Что делает |
|---|---|
| просто текст | тема рилс или просьба о правке |
| `/profile <текст>` | сохранить профиль блога: ниша, аудитория, тон, цель, формат съёмки, оффер, запреты |
| `/profile` | показать сохранённый профиль |
| `/new` | новая тема (забыть текущий диалог) |
| `/web` | вкл/выкл поиск трендов и фактов в интернете |
| `/save` | прислать последний сценарий файлом `.txt` |
| `/myid` | узнать свой Telegram ID |

## Установка

1. **Создай бота в Telegram.** Напиши [@BotFather](https://t.me/BotFather) → `/newbot` →
   придумай имя → получишь токен вида `123456789:AA...`.
2. **Получи ключ Anthropic API** на https://console.anthropic.com (нужно пополнить баланс).
3. **Установи Python 3.10+** и зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. **Настрой `.env`:** скопируй `.env.example` в `.env` и впиши токен и ключ.
5. **Запусти:**
   ```bash
   python bot.py
   ```
6. **Закрой доступ посторонним.** Напиши боту `/myid`, впиши полученное число
   в `ALLOWED_USER_IDS` в `.env` и перезапусти бота. Без этого любой, кто найдёт бота,
   сможет генерировать сценарии за твой счёт.

Бот работает, пока запущен `python bot.py`. Чтобы он работал круглосуточно,
его нужно запустить на сервере (VPS) или в облачном хостинге.

## Что важно знать

- Модель: `claude-opus-5-5`, адаптивное мышление.
- Бот не должен выдумывать факты и цифры: спорные утверждения помечает `[проверить]`,
  с `/web` приводит ссылки на источники. Перед публикацией факты всё равно стоит перепроверить.
- Профили хранятся в `data/profiles.json`. История диалога хранится в памяти
  и сбрасывается при перезапуске бота.
- Если модель отклоняет запрос по правилам безопасности, включён автоматический
  резервный режим (`fallbacks: "default"`).

## Стоимость

Оплачивается по тарифам Anthropic API за токены: https://www.anthropic.com/pricing
Цена одного сценария зависит от длины ответа и от того, включён ли `/web`.
Сам Telegram-бот бесплатный.

# 🏋️ Сайт фитнес-тренера (`site/`)

Одностраничный сайт-визитка: главный экран, обо мне, услуги, этапы работы, цены,
отзывы, частые вопросы и форма записи. Без сборки и зависимостей — просто откройте
`site/index.html` в браузере.

**Что заменить на свои данные:**
- все тексты в квадратных скобках `[...]` в `site/index.html` (имя, город, опыт, цены, контакты);
- отзывы — сейчас это шаблоны, вставьте настоящие отзывы клиентов с их согласия;
- номер WhatsApp в `WHATSAPP_NUMBER` в `site/script.js` — форма открывает чат WhatsApp
  с готовым текстом заявки (своего сервера у сайта нет);
- фото: положите файл в `site/` и в `site/style.css` для `.hero__photo` / `.about__photo`
  замените фон на `background: url("photo.jpg") center / cover;`.

**Публикация:** папку `site/` можно бесплатно разместить на GitHub Pages, Netlify или Vercel.
