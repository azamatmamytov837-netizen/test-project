# 🎬 ИИ-агент для сценариев Reels

Консольный агент на базе Claude (Anthropic API), который пишет готовые к съёмке сценарии
для Instagram Reels / TikTok / YouTube Shorts под твой блог.

Каждый сценарий содержит:
- 3 варианта хука на первые 0–3 секунды;
- раскадровку по секундам: что в кадре, что говорить, какой текст на экране;
- призыв к действию (CTA), подпись к посту, хэштеги;
- советы по съёмке, монтажу и музыке.

Можно просить правки в чате («сделай короче», «добавь юмора», «перепиши под 15 секунд») —
агент помнит контекст текущей темы.

## Установка

1. Python 3.10+.
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Получить API-ключ на https://console.anthropic.com и задать его:
   ```bash
   export ANTHROPIC_API_KEY="sk-ant-..."      # macOS / Linux
   setx ANTHROPIC_API_KEY "sk-ant-..."        # Windows (перезапусти терминал)
   ```
4. Заполнить профиль своего блога:
   ```bash
   cp profile.example.json profile.json
   ```
   и отредактировать `profile.json` (ниша, аудитория, тон, цель, формат съёмки, оффер).
   Файл `profile.json` не попадает в git.

## Запуск

```bash
python reels_agent.py                                   # чат: агент спросит тему
python reels_agent.py --topic "3 ошибки новичков в зале" # сразу с темой
python reels_agent.py --web                             # + поиск трендов и фактов в интернете
python reels_agent.py --effort high                     # глубже проработка (дольше и дороже)
```

Команды в чате:

| Команда | Что делает |
|---|---|
| `/save` | сохраняет последний ответ в `scripts/reels_<дата>.md` |
| `/new`  | начинает новую тему (очищает историю) |
| `/exit` | выход |

## Что внутри

- Модель: `claude-opus-5-5`, адаптивное мышление, потоковый вывод.
- `--web` включает серверный инструмент веб-поиска Anthropic (до 5 запросов на ответ);
  агент приводит ссылки на источники.
- Агенту запрещено выдумывать факты и цифры — спорные утверждения он помечает `[проверить]`.
- Если модель отклоняет запрос по правилам безопасности, включён автоматический
  резервный режим (`fallbacks: "default"`).

## Стоимость

Оплачивается по тарифам Anthropic API за токены: https://www.anthropic.com/pricing
Точная цена одного сценария зависит от длины ответа, `--effort` и использования `--web`.
